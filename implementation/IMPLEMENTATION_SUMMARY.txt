================================================================================
IPC CALCULATION FORMULAS
================================================================================

Instructions per Cycle (IPC) = Instructions / Cycles

EXAMPLE (Thread 4):
  Instructions = 2.37billion
  Cycles       = 4.5million
  IPC          = 2.37billion / 4.5million = 0.526

INTERPRETATION:
  IPC > 0.55 → CPU not saturated, optimal (Big-Only)
  IPC > 0.50 → Good performance (Mixed)
  IPC < 0.45 → Degraded performance (Hybrid)

Cache Hit Ratio = 100% × (Cache References - Cache Misses) / Cache References

EXAMPLE (Thread 4):
  Cache References = 12billion
  Cache Misses     = 2billion
  Hit Rate         = 100% × (10billion / 12billion) = 83.3%
